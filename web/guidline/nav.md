# 导航系统响应式规范

## 1. 移动端 (`< 768px`)
- 顶栏 Header 紧凑展示 Logo 与控制项；
- 页面内 Tab 导航栏触顶吸附：仅在 navbar 的 topline 触碰到 view 的 topline 后自动吸附 (`position: sticky; top: 0;`)，伴随深色毛玻璃加深背景防止下方卡片穿透。

## 2. 中等屏幕 / 平板 (`768px ~ 1199px`)
- 紧凑型 Sidebar (Rail 模式, 68px)：默认仅展示精巧 Icon 与状态指示点，极大化释放内容区横向空间；
- 鼠标悬停 (Hover) 时向右平滑展开为 240px 抽屉浮层，移开后自动缩回。

## 3. 完整宽屏桌面 (`>= 1200px`)
- 完整侧边栏常驻展开 (240px)，完整展示品牌全称、菜单文本、动态数字 Badge 与底部控制台；
- 底部提供折叠切换按钮 (Pin / Collapse)，支持用户自由在 Rail 态与展开态之间切换并持久化保存。
